# User List Feature Spec

## Intent

Provide a small client-side UI to add and remove user names locally.

## In scope

- Add user names
- Remove user names
- Local state only (no persistence)

## Out of scope

- Server persistence or Redux integration

## Requirements

- Title: "User List"
- Input for name, add button
- List of users with remove action

## Acceptance

- [ ] UI displays and allows adding/removing users
